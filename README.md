# 💻 DV Computadoras V11

Página web profesional para **DV Computadoras**, especializada en mantenimiento, reparación y optimización de computadoras y laptops.

El proyecto fue desarrollado con tecnologías web modernas, buscando ofrecer una experiencia rápida, profesional y adaptable para clientes desde computadoras, tablets y teléfonos móviles.


---

# 🚀 Características principales

✅ Diseño profesional responsive  
✅ Adaptación para celulares y tablets  
✅ Animaciones modernas  
✅ Menú móvil hamburguesa  
✅ Botón flotante de WhatsApp  
✅ Galería de trabajos realizados  
✅ Sección de servicios  
✅ Proceso de atención al cliente  
✅ Contadores animados  
✅ Optimización SEO básica  
✅ Compatible con GitHub Pages  


---

# 🛠️ Servicios incluidos en la página

- Mantenimiento preventivo de computadoras
- Reparación de laptops y PCs
- Instalación de Windows
- Actualización de drivers
- Cambio de discos SSD
- Eliminación de virus
- Optimización del sistema
- Recuperación de información
- Soporte técnico remoto
